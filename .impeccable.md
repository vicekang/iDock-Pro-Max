## Design Context

### Users
The owner uses this Mac app as a personal phone center for a DJI cellular module: calls, SMS, cellular data, recordings and Codex voice answering. Existing communication and background availability must remain intact.

### Brand Personality
User-selected name: **iDock Pro Max**. Quiet, precise, tactile. The creator explicitly requested Apple's current Liquid Glass design language.

### Aesthetic Direction
Native macOS 26 Liquid Glass, San Francisco system typography, SF Symbols, restrained system blue, a native window toolbar, continuous split content, and readable content surfaces. Follow the system light/dark appearance. The explicit Apple-native brief takes precedence over generic web-font guidance.

### Design Principles
1. Use real system glass APIs, with material fallbacks on older macOS.
2. Glass defines navigation and controls; dense text remains readable without stacked glass panels.
3. Let AppKit own window corners and toolbar geometry. Do not put each column into a rounded card. Use 8-point selection corners and 12-point content groups with 16/24/28-point spacing.
4. Respect Reduce Motion, Reduce Transparency and Increase Contrast; preserve keyboard navigation.
5. Brand changes must preserve bundle identity, local data, helper trust and existing authorization.

### Owner feedback (2026-09-15)
The first design felt rigid, with poor corners, layout and material quality. Avoid a full-height icon rail next to two large rounded panels. Remove stacked glass and card borders; settings must separate AI answering from general preferences.

### Implementation references
- CodeEdit (https://www.codeedit.app/): continuous native window, compact toolbar, sidebar density. Reference its layout principles, not editor-specific controls.
- Latest by Max (https://max.codes/latest/): direct list/detail relationship and restrained reading surfaces. Its website screenshot predates Liquid Glass; it is an information-layout reference only.
- Majid Jabrayilov (https://swiftwithmajid.com/2025/07/16/glassifying-custom-swiftui-views/): glass responds to its surroundings; use it on controls with actual content underneath.
- Apple, Build an AppKit app with the new design (https://developer.apple.com/videos/play/wwdc2025/310/): native toolbar glass, window concentricity, grouped controls and content extending to window edges.

### Sidebar material correction (2026-09-15)
The owner explicitly rejected the flat gray sidebar and asked for more genuine native glass. Use a native NavigationSplitView sidebar on macOS 26; legacy NSVisualEffectView.sidebar backing must not cover the system glass. Strengthen glass on search and transport controls, while preserving readable waveform/transcript content. Avoid restoring three independent full-height rounded panels.
