# 0.4.0-codex 验证记录

验证日期：2026-09-13。设备：Apple Silicon Mac、DJI 4G 模块、已登录 ChatGPT 的 Codex。

## 已通过

- 原 CellDock 实机短信发送、接收及人工电话双向声音，由机主确认。
- 完整主应用、USB / eUICC 桥接编译，安装包深度签名校验。
- 原项目核心测试：通话状态、短信 PDU/UDH、SOCKS5、VoWiFi、缓冲、存储、短信内容、录音、联系人、转发和 USB / eUICC 桥接。
- 本机 HTTP 鉴权、中文分片、请求边界与大小限制测试。
- MCP 工具映射及去重 ID 等 5 项 Python 测试；音频采样转换、20 ms 分帧、队列上限、欠载静音测试。
- MCP 已注册，真实本机状态查询通过。
- 指定模块接口的网页请求返回 HTTP 200。
- Codex App Server 用现有 ChatGPT 登录创建 GPT-Live WebRTC 会话，不提供 API Key。
- 安装在 `/Applications/CellDock.app` 的应用完成真实语音往返：输入合成的 8 kHz 电话 PCM「你好，我想预约明天下午三点，请问你是谁」，返回相应转写并用声音回答「明天下午三点预约」。收到 204,480 个 8 kHz 音频采样，其中 36,445 个采样超过音量检测阈值。
- Apple Speech 与独立识别模型依赖已移除。
- build 107 真实来电自动接听成功，电话端听到 AI 身份开场白；对方说话被正确识别，完成多轮双向对话，并在通话中确认能听见 AI 回复。
- 对方挂断后，应用保持运行、电话恢复 idle、AI 音频关闭并回到待机，自动接听仍开启。
- 修复了实机来电发现的浮窗缩放重入崩溃：去除 NSWindow 同步阻塞动画并防止重复调整大小。107 版实际来电及挂断流程未再触发该崩溃。
