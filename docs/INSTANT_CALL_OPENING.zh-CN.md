# 接通后播放本地开场白（0.4.4-codex）

## 为什么会静音几秒

2026-09-14 的一次实际来电中，本机记录的 `call.active` 到 `voice.connected` 相隔约 3.916 秒。旧版在电话音频准备好之后，才启动 Codex 进程、WebKit 音轨、WebRTC 连接，再请求模型生成开场白。这些启动步骤使接通后的前几秒没有声音。

新版在准备接听时提前启动语音连接。电话和 USB 音频通道就绪后，先把已缓存在本机的开场白直接送到电话上行，同时继续准备 AI。开场白负责问候和询问来意，随后 AI 听取并回应来电者，不再另行请求相同的 AI 问候。

## 使用自己的录音

1. 在 CellDock「设置 → Codex 电话助理」启用「接通后先播放本地开场白」（默认开启）。
2. 点击「导入我的录音」，选择 WAV、M4A、MP3 等系统能够解码的音频。
3. 点击「试听 / 停止」检查声音；如有需要，填写开场白文字，供 AI 理解已说过的内容。
4. 如果自己的录音已经告知对方会录音，勾选「我的录音已包含录音告知」。否则开启通话录音时会自动补充这段告知。

建议录 3–8 秒，例如「您好，我是机主的 AI 电话助理，请问有什么可以帮您转达？」。导入范围为 0.3–20 秒、25 MB 以内。导入时转换为电话所需的单声道 8 kHz PCM，裁掉长的首尾静音，保留短保护间隔并控制音量；来电时不再解码文件。只复制到本机应用目录，不移动或修改原文件。设置从下一通电话生效。

未导入个人录音时，使用内置中文开场白。此默认声音由 macOS Tingting 在构建素材时生成，播放时不需要联网生成。文字开场白配置用于关闭本地开场白或本地素材不可用时的 AI 回退。

## 音频衔接与边界

- 每 20 毫秒向原有电话音频链路写入一帧，避免一次塞入整个文件造成 USB 音频缓冲区溢出。播放不依赖 Mac 扬声器；「试听」按钮才会在本机播放。
- 本地开场白与 AI 输出由同一个播放器排序。提前到达的模型音频在开场白之后按原速度播放，不叠音；收到打断事件时清除待播模型回复。本地开场录音本身完整播放，因此建议简短。
- AI 尚未连接时短暂保留对方的第一句话。缓存最多 8 秒，超出会记录诊断事件；语音连通后按原速度送入，并跨过积压的静音以追赶实时音频。
- 挂断、连接失败会清空待播数据；上一通电话的异步回调不能激活下一通电话。
- 开启原声录音时，本地开场白和 AI 音频经过相同上行链路，进入原有右声道。文字记录把开场白标为「本机预录开场白」，AI 生成的转写仍可能包含未完整播放的内容。
- 本地音频不能缩短 USB 声卡准备和运营商接通的耗时；网络异常仍可能超过开场白时长。连接失败沿用原来的结束 AI 通话逻辑。

WebRTC 的说话与打断事件语义参考 [OpenAI Realtime Conversations](https://developers.openai.com/api/docs/guides/realtime-conversations)。本项目实际使用 Codex GPT-Live 的实验性实时接口，需用已安装的 Codex 版本验证，不能把公共 Realtime API 文档当作兼容保证。

## 自检

```sh
./scripts/run_tests.sh
node Tests/test_codex_realtime_audio.cjs
python3 -m unittest discover -s Tests -p 'test_codex_phone.py' -v
python3 scripts/codex_phone.py opening.status
python3 scripts/codex_phone.py agent.openingTest
```

`agent.openingTest` 用正式播放器和真实 Codex 语音连接做隔离测试，不拨号、不采集麦克风、不向模块发送测试声音。可以传入 `pcm8k`（最长 10 秒的 8 kHz PCM16 单声道 Base64）模拟来电者，验证开场后识别与回复。返回开场时长、首次可听输出时间、连接时间、转写及输出 PCM。输出 PCM 仅供检查声音顺序，不保留空闲阶段的全部墙钟停顿。

`firstOutputSeconds` 是隔离测试中本地播放器首次产生可听样本的时间。实际电话日志的 `voice.first-output-enqueued` 是通话媒体就绪后首次把可听音频交给模块队列的时间，均不等于远端手机实际听到声音的时间。真实电话还应验收接通出声、开场期间抢话、AI 回复衔接、挂断重拨和双声道录音。

## 本机数据

导入后的私有副本保存在 `~/Library/Application Support/CellDock/CodexBridge/OpeningAudio/custom.wav`，文件权限 0600，目录权限 0700。点击「使用默认开场白」只删除这份应用副本。不要把个人录音和通话数据提交到 GitHub。
